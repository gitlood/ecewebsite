# Your next chapter starts at sunrise

A scroll-from-dawn-to-morning website of researched career options for an experienced ECE head teacher in Whanganui who wants to move out of direct teaching: local employers, pay, part-time study and real stories, with sources for every figure.

The whole site is `index.html` (no build step). Research is current to 5 November 2026.

## Publish with GitHub Pages

1. Put `index.html`, `.nojekyll` and this `README.md` in the root of the repository and push to the `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose **main** and **/ (root)**, then **Save**.
4. After a minute or two the site appears at `https://<your-username>.github.io/<repository-name>/`.

GitHub Pages on a free account needs a public repository.
